Added a full band AM/FM station scan with saved, sorted Memory lists shared by all FM, MW, or SW bands and live scan results in the left panel. Each list holds up to 256 stations, while browsing, clearing, and ATS operate only within the current band; ATS preserves frequencies saved for other bands in the same list. A separate red M above the frequency unit indicates that the current frequency is saved in Memory, while a green F indicates Favorite; these appear before the tuning-mode label. The Memory menu starts with (Back), Add Current, ATS, and Clear; opening it on a saved frequency selects that entry automatically, while (Back) returns to the main menu. Quickly clicking Add Current saves immediately, while ATS and Clear open a No/Yes confirmation submenu before the action runs. Holding a saved frequency for at least 0.3 seconds also opens No/Yes, which is confirmed with a quick click. Cancelling a scan restores the previous Memory list, while a successful add or scan closes the menu. Memory result and error messages remain visible long enough to read. Previously saved per-band lists need to be rescanned. Separate V. Freq and V. Mem main-menu items select step tuning or Memory tuning directly. The original 99-slot Memory menu is now named Favorite. The Web UI also uses the Favorite name, shows the shared Memory lists separately, and can download or restore both sets together as a YAML backup.
